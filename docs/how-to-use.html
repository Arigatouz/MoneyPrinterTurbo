01 — The mechanism

What it actually does

MoneyPrinterTurbo is an orchestrator. It ships no AI models of its own; it calls services you hold accounts with, then does the video assembly locally with FFmpeg. Understanding the seven stages tells you exactly where your money goes, which credentials you need, and which part to look at when a video comes out wrong.

Three front doors drive that same pipeline — the WebUI (a browser form), the REST API, and the CLI. They read one shared config.toml and behave identically, so anything you can click you can also script.

The one thing people get wrong

There is no "video length" slider. The narration sets the duration. A 40-word script makes a ~15-second video. To make a video shorter, shorten the script — the Maximum Clip Duration setting only controls how fast the footage cuts.

Installing and launching

Pick one route. They all end at the same WebUI on port 8501.

The most isolated route. Copy config.example.toml to config.toml first so it can be mounted.

From source, step by step

shellmacOS / Linux
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo

# Install Python 3.11 and the locked dependencies
uv python install 3.11
uv sync --frozen

On Windows, run .\webui.bat instead. If you prefer plain pip, python3.11 -m venv .venv followed by pip install -r requirements.txt still works — requirements.txt is kept for exactly that.

The first launch copies config.example.toml to config.toml. That file holds your API keys in plaintext; it is already in .gitignore, and it should stay there.

Windows path gotcha

Keep the project in a path with no spaces, accents, or non-Latin characters. FFmpeg and the model loaders both choke on them, and the resulting errors do not mention the path.

04 — First run

Your first video

Open http://127.0.0.1:8501. The page is one long form in five panels. Work top to bottom.

  1. Put your keys in Basic Settings

    Expand Basic Settings at the top of the page. Under LLM Settings, choose your provider and paste its API key — each provider shows a link straight to the page where you create one. Under Material APIs, paste your Pexels or Pixabay key. Everything is written to config.toml as you type, so this is a one-time job.

  2. Describe the video

    Type a Video Subject — for example "How AI is changing everyday life". Set Script Language, or leave it on Auto Detect to follow your subject's language. This is the only field you genuinely have to fill in.

  3. Generate and review the script

    Press Generate Script & Keywords with AI. The narration lands in Video Script and the footage search terms in Video Keywords. Read both and edit freely — this is the cheapest place to fix a video. Keep the keywords in English; the stock libraries are indexed in English.

  4. Choose the shape and the voice

    Set Video Aspect Ratio — Portrait 9:16 for TikTok, Reels, and Shorts; Landscape 16:9 for YouTube. Then, under Audio Settings, leave the service on Azure TTS V1 (free Edge TTS) and pick a voice in the same language as your script. Hit Voice Sample to hear it.

  5. Check the subtitle font

    Subtitles are on by default and burned into the video. The one setting that actually breaks things is the font: it must contain your script's characters, or captions render as empty boxes. The WebUI warns you when it does not. Drop extra fonts into resource/fonts.

  6. Generate, then collect

    Press Generate Video. It runs in the background — watch the progress bar and the live log. Expect a few minutes, mostly footage downloads and the final encode. You get an inline player, a Download Video button, and an Open Folder shortcut when it finishes.

Task Manager

Every run is listed in Task Manager at the top of the page, with its status, subject, and progress. Runs survive restarts, so that is where yesterday's videos live — replay them, open their folder, or delete them and their files from there.

Audio settings

Subtitle settings

Subtitles are rendered into the video itself, not shipped as a sidecar track. You control Font, Font Size, Position (top, center, bottom, or a custom percentage from the top), Color, Outline color and width, and an optional solid or rounded Background box. Restore Subtitle Defaults undoes any experiment.

06 — On disk

Where your files go

Every run gets its own folder, and nothing is ever cleaned up automatically. If the app starts filling your disk, this is why.

treeproject root
MoneyPrinterTurbo/
├── config.toml                    # your keys and settings — treat as secret
├── resource/songs/                # bundled background music
├── resource/fonts/                # subtitle fonts — add your own here
├── models/whisper-large-v3/       # only if you use Whisper subtitles
└── storage/
    ├── cache_videos/              # downloaded clips, reused across runs
    └── tasks/<task-id>/
        ├── script.json            # the narration and the search terms
        ├── audio.mp3              # the voice-over
        ├── subtitle.srt           # the timed captions
        └── final-1.mp4            # the finished video

Because each stage writes its own artifact, you can inspect exactly where a bad video went wrong: read script.json to judge the writing, play audio.mp3 to judge the voice, open subtitle.srt to check the timing.

07 — Localization

Interface language

The WebUI ships nine translations. The language is picked in this order: the language value in your config.toml, then your browser's locale if a translation matches it, then English.

This repository pins English, so the interface is in English regardless of the browser you open it in. Change it from the dropdown in the WebUI's top bar — which saves your choice back to the file — or edit it directly:

tomlconfig.toml
[ui]
language = "en"   # zh · de · es · id · pt · ru · tr · vi
Two different languages

The interface language and the script language are independent. An English interface can happily produce Spanish narration — set Script Language in the form and pick a matching voice.

08 — Automation

API and command line

The browser is optional. Start the REST service with uv run python main.py and read the interactive docs at 127.0.0.1:8080/docs.

MethodPathPurpose
POST/api/v1/videosRun the full pipeline, get a task ID back
POST/api/v1/subtitleGenerate subtitles only
POST/api/v1/audioGenerate the voice-over only
GET/api/v1/tasksList every task
GET/api/v1/tasks/{id}Poll one task's state and progress
DELETE/api/v1/tasks/{id}Delete a task and its files
GET/api/v1/download/{path}Download a finished video
GET/healthLiveness check

Generation is asynchronous: the POST returns immediately with a task_id, and you poll until the state is complete or failed.

shellsubmit a job, then poll it
TASK=$(curl -s -X POST http://127.0.0.1:8080/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject": "How AI is changing everyday life",
       "video_aspect": "9:16"}' | jq -r '.data.task_id')

curl -s http://127.0.0.1:8080/api/v1/tasks/$TASK | jq '.data.state, .data.progress'

Command line

shellno browser required
uv run python cli.py --video-subject "How AI is changing everyday life"
uv run python cli.py --help   # every flag, documented

09 — Deployment

Before you open a port

MoneyPrinterTurbo is built as a single-user tool on a machine you control. Used that way it is fine. The shipped defaults are not safe on a shared network, and it is worth knowing exactly why.

Three facts about the defaults
  1. The REST API has no authentication. A token check exists in the code, but the line wiring it into the routers is commented out — so setting api_key does nothing today, and every endpoint is anonymous.
  2. listen_host defaults to 0.0.0.0, which publishes that anonymous API on every network interface of the host.
  3. CORS defaults to * with credentials enabled, so any website you visit while the API is running can send requests to it from your browser.

The WebUI has no login either, and its settings form pre-fills every stored API key — anyone who reaches port 8501 can read them.

The hardening checklist

tomlconfig.toml
# Bind the API to this machine only
listen_host = "127.0.0.1"

[app]
tls_verify = true   # leave on — off exposes every key you hold
shelllock CORS to the origins you actually use
export CORS_ALLOWED_ORIGINS="http://127.0.0.1:8501"
  • Never bind the WebUI to 0.0.0.0 on an untrusted network. Reach it over an SSH tunnel instead: ssh -L 8501:127.0.0.1:8501 user@host.
  • Put the API behind a reverse proxy with its own authentication if you need remote access — do not expose port 8080 directly.
  • Keep Redis private if you enable it. Task records are deserialized from it, so an untrusted writer there is an untrusted writer here.
  • Treat config.toml as a secret file. Never paste it into an issue report.
Docker is already correct

The bundled docker-compose files publish both ports on 127.0.0.1 only. Keep it that way; the container itself runs as root with the source tree mounted read-write.

10 — Troubleshooting

When it goes wrong

SymptomFix
RuntimeError: No ffmpeg exe could be found Automatic download was blocked. Grab a build from gyan.dev, extract it, and set ffmpeg_path under [app]. On Windows escape the separators: "C:\\tools\\ffmpeg.exe".
Subtitles render as empty boxes The chosen font has no glyphs for your script. Pick a font that covers the language, or drop one into resource/fonts.
Whisper model download fails
LocalEntryNotFoundError		 Download faster-whisper-large-v3 by hand and put the whole folder at models/whisper-large-v3.
OSError: [Errno 24] Too many open files Raise the descriptor limit before launching: ulimit -n 10240.
The voice reads the script in the wrong accent, or garbles it The voice does not match the script language. Change it in Audio Settings — the two are set independently.
Footage has nothing to do with the topic Edit Video Keywords by hand. They must be in English, and broad nouns retrieve better stock results than full phrases.
The video is far longer or shorter than expected Edit the script. Length follows the narration, not any setting.
Generation stalls partway with no error Check the live log for the stage name. The render stage waits on footage, subtitles, and audio — a silent failure in any branch shows up here.

Still stuck? Open an issue — include the failing stage from the log, and redact your keys first.
